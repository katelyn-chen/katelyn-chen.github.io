"The Plague's Gaze" is a mechatronic arcade game modeled after "Red Light, Green Light", where players must avoid being caught by the plague doctor and reach the end of the track. The game features mechanical components, sensors, and a PIC32 to create an interactive experience. We designed the complete game from scratch, including the SPI communication HAL, sourcing electronic components, defining and coding the event-based game logic, and designing all mechanical parts. The project is created as part of ME218A, the first part of Stanford's Smart Product Design sequence.
